# 《示例剧名》剧情背景

> 复制本文件到 `data/series_background.md`（或 config 里 `video.series_background_file` 指向的位置），
> 换成你的剧的内容。也可以直接在 Web 操作台「📖 剧情背景」页粘贴编辑。
>
> 格式只有两条硬性约定（程序按标题抽取）：
> 1. 人物介绍段的标题（`##` 或 `###`）里要含「人物」二字——每集都会用到，也是说话人命名和评论人名白名单的唯一来源；
> 2. 分集剧情的标题写成 `### 第N集：…`（或 `## 第N集`）——处理第 N 集时只抽这一段。

## 一、剧情总览

一两段话概括全剧的时代背景、主线冲突和基调。

## 二、主要人物

- **张三**：男主角，刑警队长，三十多岁。口头禅「行了行了」，下属称他「张队」。
- **李四**：女主角，法医，张三的大学同学。
- **王五**：反派，地产公司老板，人称「王总」。

> 写清楚称谓、职务、自称、彼此关系，命名准确率会明显提高——
> 程序是靠读台词里的「张队」「王总」这类称呼来判断谁是谁的。
